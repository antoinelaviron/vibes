# tableau-next-workshop-sdm-discovery

Fork of `tableau-semantic-authoring`, narrowed to discovery only, for the DF26
vibe-coding workshop.

Discovery is mandatory for hard-coded/recovery builds and optional for native
data-bound builds, where the dashboard author maps semantic roles in the widget
panel after deployment.

**Not for production.** For real Tableau Next SDM authoring, use the canonical
`tableau-semantic-authoring` skill.

See [SKILL.md](SKILL.md) for the full skill spec.
